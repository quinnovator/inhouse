# inhouse console

The web console served by `inhoused` at `https://deploy.<tailnet>.ts.net`.
It is a [TanStack Start](https://tanstack.com/start) app in SPA mode, with
TanStack Router for routes and TanStack Query for data.

## How it fits

- **No server.** `pnpm build` prerenders a single shell page and writes
  static files; `scripts/embed.mjs` copies them into
  `internal/console/dist`, which `inhoused` embeds with `go:embed`. There
  are no server functions or server routes: the control node is the only
  server.
- **Identity is the browser's.** Every request goes from the browser to
  `/v1` on the same origin, where the control node asks Tailscale who is
  calling and applies that caller's grants. The console never holds a
  credential and can't act as anyone else.
- **Strict CSP.** `internal/console` serves the shell with a policy that
  allows only this origin's files plus the shell's own inline bootstrap
  scripts, by hash. Don't add inline scripts or `style` attributes in the
  shell; use classes in `src/styles/app.css`.
- **Types mirror Go.** `src/lib/types.ts` mirrors the JSON of the Go
  structs it names. Change both together.

## Working on it

```sh
mise install                              # Go, Node and pnpm at the repo's versions
pnpm -C console install
go run ./internal/console/preview          # the real engine with fake pods, seeded services
pnpm -C console dev                        # http://localhost:3000, /v1 proxied to the preview
```

The preview's caller is an admin. Set a cookie `as` to `agent` (a
`preview-*` deployer), `viewer` or `nobody` to see other grants.

```sh
pnpm -C console typecheck
pnpm -C console test                       # unit tests for src/lib
pnpm -C console build                      # then go build ./cmd/inhoused to embed it
```

Routes live in `src/routes` (file-based); `src/routeTree.gen.ts` is
generated by the build and committed, and CI checks it is current.

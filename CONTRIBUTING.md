# Contributing

inhouse is alpha software, and **contributions are not accepted yet**. While
the design is still moving, pull requests would likely conflict with
changes already underway, so they will be closed without review.

Contributions will open during the beta period. This file will then describe
how to propose changes.

Until then:

- **Security issues:** report them privately, as described in
  [SECURITY.md](SECURITY.md).
- **Bugs and ideas:** issues are welcome once the repository is public; they
  help decide what beta should include.

# Contributing

inhouse is alpha software, and **contributions are not accepted yet**. While
the design is still moving, outside changes would likely conflict with work
already underway, so pull requests are limited to maintainers and issues are
closed.

Questions, bug reports and ideas are welcome in
[Discussions](https://github.com/quinnovator/inhouse/discussions),
and [ROADMAP.md](ROADMAP.md) says what comes next.

Contributions will open during the beta period. This file will then describe
how to propose changes.

Until then, report security issues privately as described in
[SECURITY.md](SECURITY.md).
